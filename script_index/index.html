    Script Index

    Shell Scripts

    • add-sims: Perform EXOSIMS simulations, accumulating runs into subdirectories
    • add-to-exp: perform for multiple "Experiment" runs
    • drm-to-movie: Convert DRM to movie
    • ens-path-summary: Convert DRM ensemble to plot set summarizing paths
    • exp-add-sims: Generate a Slurm batch script for an Experiment/Family
    • exp-preflight: Helper script to prepare an "Experiment" for runs
    • extract_drm_positions_driver: extract observer (etc) positions from DRM
    • html-serve: start/stop/status HTTP server
    • json-script-takeout: make a tarfile of the external files referenced by a script
    • plot-obs-timelines: Wrapper script, makes plots of observations from a DRM
    • rad-sma-rectangle-plot-driver: sh driver for radius/luminosity box-format plots
    • sandbox-test-run: perform a test run to exercise sandbox functions
    • summarize-int-times: summarize (characterization) integration times
    • tar-data: archive data files for scenario(s)
    • tar-log: archive log files for scenario(s)

    Python Scripts

    • csv2json: Convert table in CSV format to a list of JSON objects
    • csv_diff: difference between two CSV files
    • drm-grep: search through a pile of DRMs for named fields
    • drm-ls: Summarize DRMs to the terminal similar to "ls".
    • drm_tab_plot_demo: demo of a few plots using drm_tabulate as a module
    • drm_tabulate: extract named fields from a pile of DRMs Implementation details
    • ens-path-graphics: Produce diagnostic summaries of sets of DRMs, including
    • exp_loader: load an Experiment's per-Ensemble reduction info into a pandas table
    • export_ensemble_files: export selected files (plots, csv) from an ensemble
    • extract_drm_positions: Extract targets, observatory, and planet positions from DRM
    • generate_s_index: generate the s_index.json file for an Experiment
    • html-summary: Generate HTML-format summary of graphics and tables
    • input_script_check: Check EXOSIMS input script "specs" for keywords that are unused.
    • json-attr-edit: edit attributes of a JSON script
    • json-xform: Transform an EXOSIMS JSON script into a set of such scripts.
    • keepout_path_graphics: Plot targets, planets, and keepout regions, with optional DRM overlay Implementation details
    • locus_wa_dmag: provide locus of WA, dMag pairs of simulated universe
    • plot-keepout-and-obs: plot time-trace of keepout and observations within a single DRM
    • plot-keepout-and-snr: plot time-trace of keepout and snr within a single DRM
    • plot-star-obs-trace: plot time-trace of keepout and observations within a single DRM
    • plot-timeline: plot timeline of all observations within a single DRM
    • plot_drm_driver: generate all Ensemble-level DRM plots
    • python_version_check: Check python and EXOSIMS readiness to run.
    • rad-sma-rectangle-bin-plot: Radius-SMA ("Kopparapu") histogram plots
    • reduce_drm_sets: reduce a list of simulation-ensembles to summary CSV files Implementation details
    • reduce_drms: reduce a pile of DRMs to various summary CSV files Implementation details
    • select_ensembles: select from a list of simulation-ensembles
    • select_runs: select runs from a list
    • spc_extract: Extract info from SPC files into CSV
    • star_visit_pmf_tabulate: make per-star table of detection visits
    • tabulate_csv: tabulate CSV file or files according to standard processes
    • time-slew-vs-char: reduce a pile of DRMs to slew-time vs. char-time
